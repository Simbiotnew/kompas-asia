# Kompas Asia — сайт туроператора

Одностраничный сайт-пример для туристической компании Kompas Asia (Астана).
Карта маршрутов, табло выездов, туры-билеты, отзывы и заявка в WhatsApp с калькулятором.

Сделан на HTML, CSS и JavaScript без библиотек.

## Структура
- `index.html` — вся вёрстка, стили и скрипт
- `img/` — логотип и фото (временно вырезаны из Instagram, заменить на оригиналы)

## Как обновить туры
Данные лежат в массиве `TOURS` в конце `index.html`. Цена, дни выезда и фото меняются там.
